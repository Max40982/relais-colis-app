**original_problem_statement**: The user wants an ultra-fast iPhone application to manage a package pickup point (relais colis). The core requirement is to scan a package label, automatically extract the recipient's name using OCR, and update a record in their existing Airtable base.

**PRODUCT REQUIREMENTS**:
1.  **Scanning:** The app must start in camera mode. Instead of barcode scanning, it must take a photo of the package label and use OCR to extract the recipient's name.
2.  **Airtable Logic:**
    *   If the recipient is new: Create a new record. The Nom (Name) should be formatted as LASTNAME Firstname. A unique Numéro (Number) must be assigned by finding the first available integer hole in the sequence, considering only existing packages with the status En attente. The Note field should be set to 1.
    *   If the recipient exists (checked case-insensitively): Do not create a new record. Increment the package counter in the Note field (e.g., from 1 to 2).
3.  **UI/UX:**
    *   The app must be optimized for speed.
    *   The interface should be minimal.
    *   After a successful scan and validation, the app must display the assigned Numéro in a large, clear font.
    *   The on-screen keyboard should not appear after a scan.
4.  **Accuracy:**
    *   The system must be able to correctly distinguish between a first name and a last name, even when both are in uppercase on the label.

**User's preferred language**: French

**what currently exists?**
A full-stack application with an Expo (React Native) frontend and a FastAPI backend.
-   **Frontend**: A single-screen app that starts in camera mode. It allows the user to take a photo of a package label. The photo (as base64) is sent to the backend for OCR. The UI displays the extracted name for confirmation and then shows a success screen with the assigned package number.
-   **Backend**: Provides API endpoints for OCR, package processing, and listing packages. It integrates with the user's Airtable and an OCR service (Google Vision AI via Emergent LLM key). The backend logic correctly handles:
    -   Case-insensitive searching for existing recipients.
    -   Formatting names to LASTNAME Firstname using a list of common French first names to resolve ambiguity.
    -   Assigning a new, unique Numéro by finding the first available slot among En attente packages.
    -   Incrementing the package count in the Note field for existing recipients.
